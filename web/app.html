아래 4단계를 순서대로 따라가면 「이 땅에서 이 사업을 해도 되는지」까지 나옵니다. 입력한 내용은 자동 저장됩니다.

  1. 사업지 만들고 주소 입력[＋ 새 사업지]로 이름을 정하고 지번 주소를 조회하면 면적·용도지역·공시지가가 자동으로 채워집니다. 필지가 여러 개면 계속 추가하세요.
  2. 건물 용도 고르기아파트·오피스텔·지식산업센터 등 카드 하나를 고릅니다. 추천 표시가 이 땅에 맞는 용도입니다. 규모·사업비·일정은 자동으로 채워집니다.
  3. 숫자 3개만 고치기땅값 · 공사비 · 분양가를 시세·견적으로 바꾸세요. 고칠 때마다 결과가 바로 바뀝니다.
  4. 결과 확인이익·이익률과 「적합 / 검토 / 부적합」 판정이 나옵니다. 용적률 초과 같은 법규 문제도 함께 알려 줍니다.

근거 및 검토자

업체·계정 관리 시범 사용 업체 추가 · 아이디 발급 — 운영자만 보입니다

  • 업체마다 사업지 자료함이 따로 있어 다른 업체 자료는 보이지 않습니다. 브이월드 키·조례 캐시는 모든 업체가 함께 씁니다.
  • 관리자: 자기 업체 자료 전체(삭제 포함) · 직원: 조회·입력·시나리오 저장 (삭제 불가)
  • 비밀번호를 바꾸거나 계정을 지우면 그 사람의 로그인이 바로 끊깁니다. 업체를 지워도 자료는 보관소에 남습니다.

내 비밀번호 변경

접속 비밀번호 사무실 다른 PC에서 접속할 때 필요 — 이 PC에서는 자동으로 관리자

  • 관리자: 모든 기능 · 직원: 사업수지 조회·입력·시나리오 저장 가능, 사업지 삭제·영구 삭제·API 설정·비밀번호 변경 불가
  • 비밀번호는 이 PC의 data/settings.json 에 암호화(해시)되어 저장되며 원래 글자는 저장되지 않습니다. 로그인은 12시간 유지됩니다.

API 설정 필지 면적·지목·용도지역·공시지가 자동 입력 — 브이월드(국토교통부 공간정보 오픈플랫폼) 토지특성정보

  1. vworld.kr 회원가입 → 로그인
  2. 오픈API › 인증키 발급 → 서비스 URL에 http://127.0.0.1:8001 (이 프로그램 주소) 입력, 활용 API에 데이터 API(토지특성정보) 포함
  3. 발급된 인증키를 위에 붙여넣고 저장 → 사업수지 화면에서 주소를 검색하면 면적·지목·용도지역·공시지가가 자동 입력됩니다

인증키는 이 PC의 프로그램 폴더(data/settings.json)에만 저장되며 화면에는 일부만 표시됩니다. 조회 시 필지고유번호(PNU)만 브이월드로 전송됩니다.
