# 디벨로직 CI · 디자인 가이드 v1.0

화면 틀과 컴포넌트 규칙은 **청우종합관리 통합관리 프로그램(관리자 화면)** 을 기준으로 맞췄습니다.
토큰과 컴포넌트는 `web/static/ci.css` 한 파일에만 정의합니다. 화면별 CSS나 스크립트에 HEX 값을 직접 쓰지 말고 CSS 변수(`var(--...)`)를 사용합니다. 앱 안의 **설정 › CI · 디자인 가이드** 화면에서도 같은 내용을 볼 수 있습니다.

## 1. 브랜드
| 항목 | 규칙 |
|---|---|
| 국문 / 영문 | 디벨로직 / DEVELOGIC |
| 서브 카피 | 개발사업 통합 분석 |
| 심볼 | `web/static/logo.svg`: 원형 바탕 위 상승하는 세 개의 건물 매스(개발)와 기준선(로직·수지 검증) |
| 최소 크기 | 화면 24px, 인쇄 8mm. 원 바깥 여백은 지름의 1/4 이상 |
| 금지 | 비율 변형, 임의 색 변경, 그림자·외곽선 추가, 사진 위 직접 배치 |

## 3. 서체와 숫자 표기
- 서체: Pretendard (대체 서체: 맑은 고딕). 숫자에는 `tabular-nums`를 적용합니다.
- 크기: 화면 제목 23, 카드 제목 19, 본문 16, 라벨 14, 주석 13
- 금액: 표에서는 원·백만원·억원 단위를 전환할 수 있고, 요약 지표는 **억 원**(소수 1~2자리)으로 표시합니다.
- 면적: ㎡를 기본으로 하고 평을 함께 적습니다. 1평 = 400/121 ㎡(정확값)
- 음수·손실은 `--neg`(빨강), 핵심 금액은 `--figure`(딥블루)로 표시합니다.

## 4. 화면 틀
- 좌측 메뉴 224px: 브랜드 → 메뉴 그룹(구분선 + 그룹명) → 외부 링크 → 저작권 → 상태 카드
- 상단 바: 화면 제목 + 한 줄 설명, 오른쪽에 화면별 도구 버튼
- 본문 좌우 여백은 40px입니다. 화면 안에서 탭을 나눌 때는 `.subnav`(번호가 붙은 탭)를 씁니다.
- 860px 이하에서는 좌측 메뉴가 상단 가로 스크롤 메뉴로 바뀝니다(청우 관리자 화면과 같은 규칙).

## 5. 컴포넌트
- `.card` 흰 바탕, 반경 14, 패딩 22 / `.stat` 지표 카드, `.stat.hl`은 화면당 1개만 사용
- `.btn`(기본) · `.btn.secondary` · `.btn.ghost` · `.btn.danger` · `.addrow`(행 추가)
- `.chip`(정보) · `.chip.ok` · `.chip.warn` · `.chip.bad` · `.chip.gray`
- `.alert.info|warn|bad|ok` 알림 상자, `.empty` 빈 상태
- 표: `th`는 `--soft` 바탕, 금액 열에는 `.r`(오른쪽 정렬·고정폭 숫자), 합계 행은 `tr.total`, 최종 결과 행은 `tr.grand`
