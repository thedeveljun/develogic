# Cash Flow / PF 계산 명세

## 원칙
- 금액은 원 단위 Decimal 또는 정수로 저장하고 날짜별 거래를 월별 집계
- 분양계약 인식과 실제 입금 분리; 공사비 발생과 실제 지급 분리
- 차입금은 매출이 아님; 원금상환은 사업비가 아님
- 계좌별 자금 사용 제한(분양대금 관리계좌·PF 통제계좌) 별도 추적

## 후속 필수 데이터
1. 토지 필지별 계약금·중도금·잔금·취득세 납부일
2. 분양 타입별 세대수·가격·계약률·회차별 수금일
3. 공정률 S-curve, 기성 청구일·지급일, 유보금
4. 브리지론/본PF 실행·전환·만기·약정 수수료·상환 waterfall
5. 대출별 일수 계산법, 금리 변경, 미지급 이자, 자본화
6. 부가세 과세/면세·환급, 법인세 납부시점
7. 월별 계좌잔액 검산, 최대 부족액, Equity IRR

## 현 버전 제한
현재 엔진은 이벤트 수동입력 및 기본 일별 대출이자 계산만 지원. 위 상세 일정 자동생성·세무·waterfall은 미구현입니다.
