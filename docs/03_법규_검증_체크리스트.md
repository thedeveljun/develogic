# 전국 법규 검증 체크리스트

- [ ] 사업지 모든 필지 지번·지목·공부면적 확인
- [ ] 용도지역·용도지구·용도구역 및 중첩규제 확인
- [ ] 사업유형별 적용 특별법·시행령 확인
- [ ] 시·도 및 시·군·구 조례 원문·조항·시행일·개정 이력 확인
- [ ] 지구단위계획/정비계획 결정도서·고시문 확인
- [ ] 기준/허용/상한 용적률 및 건폐율 구분
- [ ] 인센티브 충족 요건과 공공기여 인정 방식 확인
- [ ] 기부채납 토지·시설·현금과 사업비 및 대지면적 영향 분리
- [ ] 건축·주차·높이·일조·교육환경·재해 등 제한 확인
- [ ] 검토자, 검토일, 원문 URL, 파일 증빙 저장

## 법규 출처 후보
국가법령정보센터 https://www.law.go.kr/ ; 토지이음 https://www.eum.go.kr/ ; 해당 지자체 자치법규 및 고시. 사이트별 접근권한과 데이터 이용조건을 확인해야 합니다.

현재 전국 17개 광역자치단체 선택 기능만 제공하며 **전국 조례 자동 검증 기능은 없습니다**. 조례를 등록했다고 적법성이 확정되지 않습니다.
