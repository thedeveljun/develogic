# 부동산 개발사업 통합 분석 — 1차 실행형 프로토타입

## 실행 (VS Code 터미널)
```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```
브라우저 `http://127.0.0.1:8000` / API 문서 `http://127.0.0.1:8000/docs`.

테스트: `python -m unittest discover -s tests -v`

## 현재 구현
- 일반 공동주택 및 역세권 정비사업 유형 구분
- 날짜별 사업수입·사업비·Equity·대출 실행·상환
- 대출별 한도 및 일별 기초잔액 이자 계산, 월별 지급
- 월별 집계, 월말 잔액, 자금 부족액, 미지급 이자 표시
- JSON API 및 간단한 브라우저 테스트 화면

## 중요한 한계
**본 버전은 검증용 MVP이며 실사업지 의사결정용 완성 모델이 아닙니다.**
업로드 엑셀의 수치·수식이 자동 반영된 것이 아닙니다. 샘플 JSON은 가상 데이터입니다.
- 실제 금융약정의 대출 실행 순서, 선이자, 중도상환수수료, 이자 자본화, 브리지→본PF 전환, 분양대금 통제계좌, 지급유보금, 대출 만기상환은 미구현
- 공정률 자동배분, 계약금·중도금 스케줄, 부가세·법인세, IRR, 정비사업 공공기여/임대주택 산정은 미구현
- 일별 기초잔액 이자 방식이며 실제 금융약정서에 따라 계산법이 달라짐
- 날짜 입력은 ISO 형식 YYYY-MM-DD; 월말 이자 지급. 프로젝트 종료일까지 발생한 미지급 이자는 별도 표시
- 법규 검토는 필요 법령 목록만 제공하며 용적률/건폐율 자동 판정은 미구현
- 금액은 JSON 숫자로 수신되므로 **초대형 금액의 정확한 입력을 위해 향후 문자열 Decimal 스키마로 변경 권장**

## 신규 웹 화면 및 법규 검토 (v0.2)
- 실행 후 http://127.0.0.1:8000/dashboard 에서 지자체별 조례 검토와 Cash Flow를 이용할 수 있습니다.
- POST /api/v1/legal-review : 검증 등록된 조례의 **일반 상한만** 반환하며 개별 사업지의 허가 가능성은 판단하지 않습니다.
- 현재 조례 데이터는 경기도 광주시 일부 주거지역(2026-04-15 시행) 및 서울 역세권 장기전세주택 정의(2026-05-18 시행)만 포함합니다. 그 외 지자체·특별 인센티브는 미확인 처리합니다.
- 지구단위계획·정비계획·공공기여·복합용도지역·부가세·실제 분양 및 공정 스케줄은 아직 자동 연결되지 않았습니다.
- 조례 링크: https://www.law.go.kr/ordinInfoP.do?gubun=ELIS&ordinSeq=2123363 , https://www.law.go.kr/ordinInfoP.do?ordinSeq=2130153
- 법규 검토 결과는 현재 Cash Flow의 수입·비용을 자동 수정하지 않습니다. 해당 연계는 검증된 면적·원가·분양계획 입력 규격을 구축한 뒤 개발해야 합니다.

## v0.3 전국 지자체 선택 / 근거 기반 법규 검토

- 웹: `http://127.0.0.1:8000/nationwide`
- 기존 현금흐름 웹: `http://127.0.0.1:8000/dashboard`
- API: `GET /api/v2/provinces`, `POST /api/v2/ordinances`, `POST /api/v2/feasibility`
- 전국 17개 광역지자체 선택 지원. 시군구는 정확한 공식 명칭으로 직접 입력합니다.
- 법규 자료는 **자동 수집·법적 검증되지 않습니다**. 검토자가 조례 시행일·조항·원문 URL을 입력한 규칙만 조회합니다.
- 동일 날짜에 복수 규칙이 충돌하거나 규칙이 없으면 수지 계산을 차단합니다.
- 필지별 중첩규제, 지구단위/정비계획, 산정 대지면적 미확정 시에도 차단합니다.
- 산출된 사업수지는 **가정 기반 단순 사업성**이며 토지비/공사비/공공기여의 세부 항목, 지하층, 부가세, 법인세, PF 비용을 모두 포괄하는 최종 사업수지가 아닙니다.
- Cash Flow 엔진은 기존과 같이 수입/지출/차입 이벤트를 수동 입력합니다. 법규 수지의 월별 자동 분배는 미구현입니다.
- 조례 등록 API는 **인증 기능이 없는 로컬 개발 전용**입니다. 인터넷에 직접 공개하지 마세요. 실제 운영 전 로그인, 권한, 감사로그, 조례 원문 검증 및 갱신 워크플로가 필요합니다.
- 설치: `python -m venv .venv` 후 Windows에서는 `.venv\\Scripts\\python.exe -m pip install -r requirements.txt`, `.venv\\Scripts\\python.exe -m uvicorn app.main:app --reload`.
- 테스트: `python -m unittest discover -s tests -v`

## v0.4 통합 화면 · 시행사 사업수지 · CI

- 모든 화면이 하나의 앱(`web/app.html`)으로 통합되었습니다. 좌측 메뉴로 화면을 전환합니다. 디자인은 청우종합관리 관리자 화면 기준입니다.
  - `http://127.0.0.1:8000/` 종합 현황 · `#proforma` 사업수지 분석 · `#cashflow` Cash Flow · `#feasibility` 법규 검토
  - 이전 주소 `/dashboard`, `/nationwide`도 계속 동작합니다.
- **사업수지 분석** (`POST /api/v3/proforma`, `app/proforma.py`)
  - 타입별 분양계획(전용·공급면적, 세대수, 평당가) / 85㎡ 초과·비주택 건물분 부가세 / 발코니 확장 / 분양률·분양가 조정
  - 사업비 8개 분류: 항목마다 산정 기준(정액, 대지·지상·지하·연면적·공급면적 평당, 세대당, 월 단위, 토지비·공사비·분양대금·공동주택 분양대금·전체 대비 %)을 선택
  - 금융: 자기자본, 대출 트랜치(금리·기간·평균 인출률·수수료), 중도금 대출이자 시행사 부담분
  - 법인세(누진 구간 수정 가능, 지방소득세 포함), BEP 분양률(정확해), 분양률×분양가 민감도, 분양가 하락 허용폭
  - 입력하면 자동으로 다시 계산되고, 시나리오 저장(브라우저)·JSON 내보내기/가져오기·인쇄를 지원합니다.
  - 샘플(`samples/proforma.json`)은 **가상 데이터**입니다. 세율·부담금·부가세 안분은 반드시 세무·인허가 검토로 확정하세요.
